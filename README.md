# OS Simulation - Run Guide

## 1. Download & Extract

- Download the project folder from Google Drive as a `.zip` file. _(Do not view files in the Drive preview)._
- Extract the `.zip` file to your computer.

## 2. Start the Server

Open your terminal or command prompt, navigate to the extracted folder (where the `manage.py` file is located), and run the following commands:

```bash
# Install the required dependencies
pip install -r requirements.txt

# Start the local serverS
python manage.py runserver
click http://127.0.0.1:8000/ 
```
